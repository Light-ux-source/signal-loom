# 后续开发路线

## P0：让 MVP 更可靠

- 将关键词、信号和通知状态保存到 SQLite 或其他轻量数据库
- 将自动扫描从浏览器定时器迁移到服务端 Cron 或队列
- 增加扫描超时、重试、指数退避和上游错误分类
- 为 `/api/scan` 增加真正的 HTTP 集成测试
- 在信息卡片中展示原始 X 链接和抓取时间

## P1：完善产品体验

- 增加扫描间隔设置和单关键词启停
- 增加通知中心详情，而不只显示未读数量
- 增加热点去重的持久化规则和相似内容合并
- 增加可信度解释、风险原因和一手来源跳转
- 补充桌面、平板和手机的浏览器自动化验收

## P2：封装 Skill

- 固化关键词、扫描、AI 分析和通知的命令接口
- 编写 Skill 的输入输出协议与错误处理
- 添加 `.env` 检查和 Demo fallback
- 用独立验收案例验证 Skill 与网页版使用同一套扫描逻辑

## 设计约束

- 所有用户可见热点内容必须是中文
- AI 只做风险和可信度评估，不宣称绝对事实
- 不把任何真实 API Key 写入仓库
- 小工具优先保持单仓库和低运维复杂度
