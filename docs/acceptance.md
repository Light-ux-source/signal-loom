# 验收清单

## 网页功能

- [ ] 点击 `立即扫描` 后显示扫描状态，并请求 `/api/scan`
- [ ] 点击左侧关键词可以筛选信息流
- [ ] 点击 `+` 可以添加新的中文监控关键词，并立即触发扫描
- [ ] 搜索框可以按中文标题、摘要和作者过滤
- [ ] 新热点会更新未读计数并显示站内提示
- [ ] 浏览器允许通知后，新热点会触发系统通知
- [ ] 不显示扫描历史、已保存和已读操作
- [ ] 没有密钥时页面仍可正常运行
- [ ] 375px、768px、桌面宽度下无横向溢出

## 服务功能

- [ ] Demo 模式返回结构化信号
- [ ] 配置 `X_API_KEY` 后调用 TwitterAPI.io Advanced Search
- [ ] 配置 OpenRouter Key 后返回 AI 评分
- [ ] X 查询和 AI 输出只保留中文内容
- [ ] 空关键词返回 400
- [ ] 上游失败返回 502
